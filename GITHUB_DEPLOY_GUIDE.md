## 📲 Cara Push ke GitHub Akun Anda dari HP:

1. Di layar AI Studio ini (pojok kanan atas), klik tombol **Settings** (ikon gerigi) atau tombol **Export / GitHub**.
2. Pilih **"Push to GitHub"** (atau hubungkan akun GitHub Anda `pututadif`).
3. Pilih repository baru atau repository yang ingin Anda tuju, lalu klik **Commit & Push**.

---

## ⚡ Cara Otomatis GitHub Membuatkan APK & Deploy:

Setelah Anda Push:
1. Buka repository Anda di [https://github.com](https://github.com) lewat browser HP.
2. Klik tab **Actions**.
3. Anda akan melihat alur kerja **"Build Android APK Release & Deploy Modal"** sedang berjalan secara otomatis:
   - ✅ **Job 1 (Build APK)**: Mengompilasi aplikasi Android menjadi file `.apk` siap install.
   - ✅ **Job 2 (Deploy Modal)**: Menerapkan backend Python HunyuanVideo DiT ke akun Modal Anda menggunakan token yang sudah disematkan.

## 📥 Cara Download File APK ke HP:

1. Di tab **Actions** GitHub, klik alur kerja yang sudah selesai (centang hijau ✅).
2. Scroll ke bagian paling bawah ke sub-judul **Artifacts**.
3. Klik **`PAP-AI-Generator-App`** untuk mendownload file `.apk`.
4. Buka file yang diunduh di HP Anda lalu pilih **Install**. Aplikasi siap langsung dipakai!
